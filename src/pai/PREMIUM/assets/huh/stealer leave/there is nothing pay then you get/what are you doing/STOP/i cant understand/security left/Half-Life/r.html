HALF‑LIFE SDSG WEBPORT — READ THIS FIRST

When the SDSG webport asks you for your Half‑Life installation, do not guess. Point it to the correct folder or you will break it and then blame the wrong thing.

The loader does NOT take loose files. It expects a single ZIP archive of the entire valve folder. This includes pak0.pak, maps, models, sound, and scripts. If you only give it one file, it will fail. This is not clever hacking, it is just wrong input.

Supported Games

Each expansion has its own folder. Pick the right one or expect missing maps, broken models, or straight‑up crashes.

Browser Behavior

If your browser warns about popups or file access, allow it. The loader cannot function without filesystem permission. This is how web ports work.

This is experimental. Visual glitches, audio desync, missing effects, and bad performance are normal. Do not act shocked.

Internet is required for the initial load so assets can cache. After that, offline play may work, but audio streaming is unreliable.

This project is fan‑made and non‑commercial. Half‑Life is owned by Valve. Use your own legally obtained copy. Nobody here is handing you free games.

GoldSrc was never meant to run in a browser. The fact this boots at all is a miracle.

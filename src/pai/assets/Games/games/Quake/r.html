UNDERTALE / DELTARUNE SDSG WEBPORT — READ THIS

Step 1 — Install SDSG

  • Download the latest SDSG release from GitHub: Latest Release
  • If GitHub is blocked, use the mirror:Google Drive (SPBOE)
  • Or use the universal ZIP installer:Universal Installer (ZIP)
After downloading:
  1. Extract the archive.
  2. Place the folder somewhere permanent (not Downloads).
  3. Run SDSG.
If you cannot install SDSG correctly, nothing below will work. Fix that first.

Step 2 — Provide Your Game Files

When the webport asks for your Undertale or Deltarune install, point it to:
%SDSG INSTALL%/src/pai/assets/data/UTDR
Inside that folder you will see:
  • UT
  • DR
Choose the correct one and select the file:
data.win
That file contains the actual game data. If you select anything else, it will fail. This is not mysterious.

Browser Behavior

If the browser blocks a popup or file access request, allow it. The loader requires filesystem permission to function.
This is beta software. Bugs, broken music offline, and random glitches are normal. Do not expect perfection.
Wi-Fi is required for the first load so assets can cache. After caching, offline play may work, but music reliability varies.This webport was not created by me.

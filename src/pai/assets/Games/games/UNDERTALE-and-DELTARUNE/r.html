Click either My music mods(you dont need the install) or the launcher through there do what ever but you have to reload sdsg sadly..

When the webport asks for your Undertale or Deltarune install, follow this exact path to avoid breaking everything: 

%SDSG INSTALL%/src/pai/assets/data/UTDR

Inside that last folder you’ll see two folders:

  • UT
  • DR

Pick either Undertale or Deltarune, then select the file named data.win. That’s the real game data the webport loader needs. (in deltarune for extra security you need a pin instead)

Install Methods

  • If you don’t have SDSG installed, grab it from Latest Version or if blocked Google Drive (SPBOE)
  • ZIP INSTALLER (UNIVERSAL): Click here
  • Manual: Point the loader to your own Undertale/Deltarune data.win file inside %SDSG INSTALL%/src/pai/assets/data/UTDR/UT or .../DR

If the browser complains about a popup being blocked, just allow it. It’s safe — seriously. The creator (Shortpie) and I both use these builds ourselves.

This is a beta. Bugs exist. Broken music offline is normal. Don’t throw a tantrum because it’s not flawless.

Wi-Fi is required for the initial load. After everything fully caches, you can go offline and the game should still run — music might be hit or miss.

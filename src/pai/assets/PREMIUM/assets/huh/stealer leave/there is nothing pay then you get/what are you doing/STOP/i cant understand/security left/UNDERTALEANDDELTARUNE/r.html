Undertale / Deltarune Webport — How to Actually Get It Working

When the webport asks for your Undertale or Deltarune install, follow this exact path to avoid breaking everything:

Your SDSG install → src → pai → assets → PREMIUM → assets

Inside that last folder you’ll see three folders:

  • huh
  • Undertale
  • Deltarune

Do NOT pick huh. That folder is a deliberate maze made to waste pirates’ time because they didn’t pay the $20 for premium. Ignore it entirely.

Pick either Undertale or Deltarune, then select the file named data.win inside. That’s the real game data the webport loader needs.

If the browser complains about a popup being blocked, just allow it. It’s safe — seriously. The creator (Shortpie) and I both use these builds ourselves.

This is a beta. Bugs exist. Broken music offline is normal. Don’t throw a tantrum because it’s not flawless.

Wi‑Fi is required for the initial load. After everything fully caches, you can go offline and the game should still run — music might be hit or miss.

The webport wasn’t made by me. Full credit goes to Shortpie for making this entire thing possible.

Enjoy playing Undertale and Deltarune through the webport inside SDSG. Consider yourself lucky this even works at all.

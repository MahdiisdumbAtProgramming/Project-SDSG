# Project‑SDSG  
*(School Defying Software Games)*

## 🚀 What is this  
Project‑SDSG is a collection of local HTML5 games designed to run on school or restricted computers. The games require **no WiFi** and are built so that they’re unlikely to be blocked by school network filters. The goal: fun, fast, and offline‑friendly games — made solo by me (Mahdiisdumb / Mahdi Studios).  

## 🔧 Why this exists  
- Many schools block gaming websites. SDSG gives access to games without needing an internet connection.  
- It’s built to be lightweight and self‑contained so students can play games on any school computer without admin privileges or external dependencies.  
- It’s my personal project: a playground in code, testing my HTML5 / JS / frontend skills, and building something fun for peers.

✅ What works / what to expect

HTML5 + JavaScript games that run fully offline.

Minimal dependencies beyond a web browser.

Simple, lightweight games — good for old / restricted hardware.

🎯 What this project is not

Not a polished “gaming platform” — no user accounts, online scoreboards, or authentication.

No guarantee that every school’s filters will allow local files.

Not a commercial product — this is a personal, hobby‑level project.

🙋 About the author / Contact

🧑‍💻 How to contribute

Fork the repo, add new games (within src/), or improve existing ones.

Ensure new games follow the same structure (self-contained HTML/JS/CSS, no external network calls).

Submit a Pull Request with a clear description of changes.

⚠️ Known limitations / disclaimers

Game compatibility may vary depending on the browser; use modern browsers for best results.

Performance may suffer on old hardware — avoid heavy graphics or large assets.

Support may be limited or irregular, as this is a personal project.
